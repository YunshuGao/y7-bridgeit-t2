Your prep before assigning Week 2 to students

Hi Ms Gao. Before students touch this tool, spend 30 minutes working through these 5 mini-tasks yourself. Take a screenshot at each step — you can drop those into the placeholder slots throughout this page (look for the orange dashed boxes).

  1. Open the tool in a fresh browser tab. Note the layout — toolbox on one side, big blank workspace in the middle, "Run / Test" button somewhere prominent. Take Screenshot #1: the empty workspace.
  2. Place 4 nodes in a square shape (click → click → click → click). Connect them with 4 members to form a square. Take Screenshot #2: the square bridge.
  3. Run the load test. The square should FAIL — members will deform, change colour, or break. Take Screenshot #3: the failed square (this is the "WHY triangles?" lesson in one image).
  4. Add a diagonal across the square (one member connecting opposite corners). It now has 2 triangles. Run the test again. Should PASS. Take Screenshot #4: the passing triangulated bridge with red/blue colours visible.
  5. Find the SAVE feature. Does it save online? Save to file? Require login? Note this — students will need to know how to keep their designs across the 8 weeks.

Once you've done these 5 tasks, you understand the tool well enough to teach Week 2. Each subsequent week's prep takes ~10 minutes.
