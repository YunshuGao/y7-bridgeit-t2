Before you assign Week 2 to students

Hi Ms Gao. The good news: I've now seen the actual ASCE Bridge Designer Cloud Edition, so the tutorial below uses real menu names, real buttons, real hot keys. Spend 30 minutes working through Week 2 yourself — by the end of it, you'll be ready to teach the full 8-week sequence.

  1. Open the tool in a fresh browser tab. The "Design tip of the day" window appears — click Close.
  2. Click File → Load template.... Pick any template. A working starter bridge appears.
  3. Press Alt-T to run the load test. A truck drives across. Watch the colours: RED = compression, BLUE = tension.
  4. Press Alt-D to return to the drawing board. Click Report → Cost calculations to see the 4-part cost breakdown.
  5. Click Report → Member analysis — this is the engineering-grade data report. Scan it. Close it.
  6. Try File → Save — files save as .bdc on your computer. Handy for students to share designs with you.

Done? You now know the tool well enough to teach all 8 weeks. Each subsequent week's prep is ~10 min.
